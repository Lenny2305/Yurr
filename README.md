# Felix Jump

Ein 2D-Plattformspiel, in dem Felix durch verschiedene Level springt, Feinde besiegt und Herausforderungen meistert.

## 🎮 Steuerung

| Taste | Aktion |
|-------|--------|
| **A / D** oder **Pfeiltasten** | Links / Rechts bewegen |
| **Leertaste** | Springen |
| **S** oder **Pfeil runter** | Ducken |
| **Mausklick** | Schießen |
| **ESC** | Pause-Menü |

## ✨ Features

- Mehrere Level mit steigendem Schwierigkeitsgrad
- Verschiedene Skins (Felix, Batman)
- Feinde und Kampfsystem
- Teleporter
- Lautstärkeregelung
- Pause-Menü

## 💻 Systemvoraussetzungen

- **Betriebssystem:** Windows 64-Bit
- **Laufzeitumgebung:** Mono / .NET

## 🚀 Starten

1. Repository herunterladen oder klonen
2. `Felix Jump.exe` ausführen
